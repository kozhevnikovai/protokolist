# Тестовая запись

`meeting-3-speakers.ogg` — «встреча» из 18 фраз трёх дикторов (2 мин 46 с), склеенная из тестовой части
[Russian LibriSpeech](https://huggingface.co/datasets/bond005/rulibrispeech) (аудиокниги LibriVox — общественное достояние).
`meeting-3-speakers.json` — эталон: кто и когда говорил, точный текст. По нему CI считает WER и точность спикеров.
