# Как помочь проекту

- **Плохо распознало или перепутало спикеров?** Откройте issue «Ошибка»: что сказали и что получилось, сколько было участников, как записывали (наушники, колонки, онлайн или живая встреча). Не прикладывайте записи с персональными данными.
- **Новый шаблон протокола.** Добавьте его в `src/protocol/templates.ts` (фокус и дополнительные поля) и эталонную встречу в `evals/meetings/` — по ней проверяется качество.
- **Новая интеграция.** Функция отправки — в `src/integrations/`, все сетевые запросы — только через `netFetch` (так их видит счётчик и блокирует офлайн-режим), тест с подменой `fetch` — в `test/export.test.ts`.
- **Словарь и сроки.** Правила дат — `src/protocol/dates.ts`, тесты — `test/core.test.ts`.

Перед pull request: `npm run typecheck && npm test`. Если меняли распознавание — `node test/e2e.mjs`, если промпт или шаблоны — `npm run eval`.
