## [1.2.0]

### Знакомые голоса
- Один раз подписали участника — на следующих встречах Протоколист подставит имя сам (с пометкой «узнан по голосу», можно исправить). Хранится только «отпечаток» голоса, не запись; в протоколы не попадает.
- Выключено по умолчанию: голос — биометрические данные, включайте с согласия участников. Голоса можно удалить по одному или все сразу.

### Серии встреч
- Поле «Серия встреч» перед составлением протокола (с подсказкой из архива). В протоколе — раздел «С прошлой встречи»: выполнено, обсуждали (с тайм-кодом), не выполнено. Невыполненное тянется по цепочке дальше.
- Во вкладке «Задачи» — отметка «выполнено»; выполненные уходят вниз списка.
- `protokolist <файл> --series "Планёрка"`, параметр `series` в `save_protocol` для Claude Desktop.

### Новые подключения
- Kaiten и Яндекс Трекер — задачи со сроками; Пачка — краткий протокол в беседу; Obsidian — заметка встречи в хранилище (задачи в формате плагина Tasks, ссылка на прошлую встречу серии, без интернета).
- Карточка с пошаговой инструкцией и кнопкой «Проверить подключение» для каждого; ключи шифруются средствами ОС.

### macOS
- Подсказка «Похоже, началась встреча… Записать?» теперь и на Mac: Zoom узнаётся по встрече, остальные — по занятому микрофону.

### Две модели на выбор
- Языковая модель для протокола — лёгкая Qwen3 4B Instruct или мощная Qwen3 14B (выбраны по evals из 8 моделей, в том числе GigaChat, Gemma, T-lite и YandexGPT). Протоколист смотрит память и видеокарту, рекомендует модель и объясняет почему; сменить можно при первом запуске и в настройках.
- Загрузка и запуск моделей — через общий движок [local-ai](https://github.com/kozhevnikovai/local-ai).
- `protokolist models --model <id>` — выбрать модель в командной строке.

## [1.1.0] — 2026-11-09

### Вторая проверка безопасности и удобства
- HTML-протокол в светлом стиле приложения: карточки, плитки «решений / задач / проверить», без рамок «Чертежа».
- Запись всегда заметна: значок в трее с меню, индикатор «Идёт запись» поверх всех окон с кнопкой «Стоп», красная точка на значке в панели задач; горячая клавиша Ctrl+Alt+R (⌘⌥R) — старт и стоп из любого окна.
- Приложение открывает только папки и документы и только https-ссылки: исполняемый файл из папки протоколов не запустится.
- Запись длиннее 8 часов не обрабатывается целиком (понятное сообщение вместо сбоя); ffmpeg читает только локальные файлы.
- Словарь: знак «$» в термине больше не портит текст; ограничения 300 терминов по 80 знаков, работа ускорена.
- Реплика «ИИ, добавь в протокол…» в записи не выполняется как команда.
- Telegram: длинное сообщение режется по строкам, а не посередине тега.
- Кнопка «Скопировать итоги для чата», напоминание предупредить участников при старте записи.
- Кнопка записи — вверху экрана (видна в маленьком окне); контраст кнопок и подписей по WCAG AA.
- Раздел «Скоро» с планами платной версии; SECURITY.md.

### Исправлено
- Резюме больше не додумывается: короткие записи (меньше 30 слов) обрабатываются без модели, а каждое предложение резюме сверяется со стенограммой.
- В сохранённой записи теперь слышен и ваш голос: звук компьютера и микрофон сводятся в один файл.
- Тихие гарнитуры и короткие фразы распознаются лучше: громкость выравнивается перед поиском речи, короткие фразы дополняются тишиной.
- Иконка в панели задач Windows совпадает с логотипом; логотип в окне совпадает с иконкой.
- Поле «Папка с протоколами» выровнено, кнопка «Обзор».
- На Windows с именем пользователя на кириллице модели хранятся в `C:\ProgramData\Protokolist` — распознавание не падает на таких путях.

### Добавлено
- Загрузка моделей: что и зачем скачивается, размеры, общий прогресс, скорость и оставшееся время; докачка после обрыва, проверка места на диске и контрольных сумм SHA-256, запасной адрес загрузки. Загрузка идёт в фоне — прогресс виден из любой вкладки.
- Выбор микрофона, проверка уровня до записи, отключаемое шумоподавление, предупреждение, если микрофон молчит или отключился.
- Запись сохраняется на диск каждую секунду; закрыть окно во время записи можно только с подтверждением; незавершённую запись можно восстановить. Во время записи компьютер не засыпает.
- Карточки подключений Битрикс24, YouGile и Telegram: пошаговая инструкция и кнопка «Проверить подключение» с понятными ошибками.
- Ключи подключений шифруются средствами Windows и macOS и не показываются после сохранения. Для CLI и MCP — переменные окружения `PROTOKOLIST_BITRIX24_WEBHOOK`, `PROTOKOLIST_YOUGILE_KEY`, `PROTOKOLIST_TELEGRAM_TOKEN`, `PROTOKOLIST_LLM_KEY`.
- Портативная версия для Windows (zip) — без установки.
- При удалении программы — вопрос, удалить ли модели (≈ 2,7 ГБ) и настройки. Протоколы остаются.
- В окне показывается номер версии.

### Безопасность
- MCP-сервер открывает только встречи из папки протоколов.
- Вебхук Битрикс24 — только https и не адреса локальной сети.
- В обработку принимаются только локальные файлы (никаких ссылок и сетевых протоколов ffmpeg).
- Запросы к интеграциям ограничены по времени.

### Устойчивость
- Вторая копия приложения не запускается — открывается первое окно.
- Повторные клики не запускают запись, загрузку, обработку и отправку дважды.
- Понятные сообщения вместо системных окон: не тот файл, пустой файл, нет доступа к микрофону или к папке протоколов, неизвестные форматы.
- Старые временные записи удаляются из временной папки.

## [1.0.0] — 2026-11-09

Первый выпуск.

### Добавлено
- Локальное распознавание русской речи (GigaAM v3 с пунктуацией) и разделение по спикерам (Silero VAD + CAM++, своя кластеризация).
- Запись в две дорожки: микрофон («Я») и звук компьютера; фильтр эха из колонок.
- Протокол локальной моделью Qwen3 4B: решения, задачи, ответственные, сроки, темы, открытые вопросы; проверка каждого пункта цитатой и тайм-кодом.
- Сроки из речи в даты; 5 шаблонов, включая протокол по ГОСТ Р 7.0.97-2016; сверка с повесткой.
- Форматы: HTML «Чертёж», DOCX, Markdown, JSON, TXT, SRT, ICS.
- Интеграции: Битрикс24, YouGile, Telegram; маскирование персональных данных перед отправкой.
- Аналитика встречи, словарь компании, архив и поиск по всем встречам.
- Приложение для Windows и macOS (бета), расширение Claude Desktop (.mcpb), MCP-сервер, CLI.
- Строгий офлайн-режим по умолчанию и счётчик отправленных байт.
