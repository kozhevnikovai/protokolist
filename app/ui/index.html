    Настройки

    01Приватность

    Хранится только «отпечаток» голоса (набор чисел, не запись) в папке Протоколиста на этом компьютере. Голос — биометрические данные: включайте, если участники согласны (152-ФЗ, ст. 11).

    02Протокол

    Распознавание иногда пишет названия и фамилии «на слух». Слева от «=» — как должно быть в протоколе, справа через запятую — как это могут произнести. Строка без «=» просто подсказывает правильное написание имени или термина.

    Битрикс24

    Создаёт задачи из протокола: текст, ответственный (по имени), срок и цитата из встречи.

    Где взять вебхук — 4 шага
    1. Битрикс24 → «Разработчикам» → «Другое» → «Входящий вебхук».
    2. В правах отметьте «Задачи (task)» и «Пользователи (user)».
    3. Нажмите «Сохранить» и скопируйте адрес вебхука.
    4. Вставьте сюда и нажмите «Проверить».

    YouGile

    Кладёт задачи из протокола в выбранную колонку доски, с исполнителем и сроком.

    Где взять ключ и ID колонки — 4 шага
    1. YouGile → «Настройки компании» → «API» → «Создать ключ».
    2. Скопируйте ключ и вставьте ниже.
    3. На доске откройте меню колонки → «Скопировать ID».
    4. Вставьте ID и нажмите «Проверить».

    Telegram

    Присылает краткий протокол (решения и задачи) и файл .docx в ваш чат или группу.

    Как подключить бота — 4 шага
    1. Напишите @BotFather → /newbot, придумайте имя — получите токен.
    2. Напишите своему боту /start (или добавьте его в группу).
    3. ID чата подскажет бот @userinfobot (для группы — число с минусом).
    4. Вставьте токен и ID и нажмите «Проверить».

    Kaiten

    Создаёт карточки задач на доске: текст, срок, ответственный и цитата — в описании.

    Где взять ключ и ID — 4 шага
    1. Kaiten → аватар → «Профиль» → «API-ключи» → «Создать».
    2. Откройте доску: в адресе …/boards/число — это ID доски.
    3. ID колонки — в меню колонки «Скопировать ссылку» (последнее число) или спросите администратора.
    4. Вставьте адрес, ключ и ID и нажмите «Проверить».

    Яндекс Трекер

    Создаёт задачи в очереди со сроком; ответственный со слов и цитата — в описании.

    Где взять токен и ID организации — 4 шага
    1. Получите OAuth-токен с правами Трекера (oauth.yandex.ru, приложение с доступом «Чтение и запись в трекер»).
    2. ID организации: Трекер → «Администрирование» → «Организации».
    3. Отметьте «Яндекс Cloud», если организация в Cloud, а не в Яндекс 360.
    4. Ключ очереди — латиницей из адреса очереди (например, SALES).

    Пачка

    Присылает краткий протокол — решения и задачи — в беседу команды.

    Как подключить — 3 шага
    1. Пачка → «Автоматизации» → «Интеграции» → «API» — скопируйте токен доступа.
    2. Откройте беседу: число в конце адреса — ID чата. Добавьте в неё бота, если токен ботовый.
    3. Вставьте токен и ID и нажмите «Проверить».

    Obsidian

    Сохраняет заметку встречи в ваше хранилище: решения, задачи с датами (формат плагина Tasks), ссылка на прошлую встречу серии. Без интернета.

    Ключи хранятся на этом компьютере в зашифрованном виде (средствами Windows или macOS) и не показываются после сохранения.
