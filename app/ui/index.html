    Битрикс24

    Создаёт задачи из протокола: текст, ответственный (по имени), срок и цитата из встречи.

    Где взять вебхук — 4 шага
    1. Битрикс24 → «Разработчикам» → «Другое» → «Входящий вебхук».
    2. В правах отметьте «Задачи (task)» и «Пользователи (user)».
    3. Нажмите «Сохранить» и скопируйте адрес вебхука.
    4. Вставьте сюда и нажмите «Проверить».

    YouGile

    Кладёт задачи из протокола в выбранную колонку доски, с исполнителем и сроком.

    Где взять ключ и ID колонки — 4 шага
    1. YouGile → «Настройки компании» → «API» → «Создать ключ».
    2. Скопируйте ключ и вставьте ниже.
    3. На доске откройте меню колонки → «Скопировать ID».
    4. Вставьте ID и нажмите «Проверить».

    Telegram

    Присылает краткий протокол (решения и задачи) и файл .docx в ваш чат или группу.

    Как подключить бота — 4 шага
    1. Напишите @BotFather → /newbot, придумайте имя — получите токен.
    2. Напишите своему боту /start (или добавьте его в группу).
    3. ID чата подскажет бот @userinfobot (для группы — число с минусом).
    4. Вставьте токен и ID и нажмите «Проверить».

    Ключи хранятся на этом компьютере в зашифрованном виде (средствами Windows или macOS) и не показываются после сохранения.
